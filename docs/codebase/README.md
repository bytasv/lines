# Codebase documentation

Human-readable docs live under `docs/codebase/features/` and `docs/codebase/decisions/`.
`index.json` is the machine-readable navigation index (features, entry points, symbols, tests).

Source code is authoritative. This documents only areas touched by completed tasks —
it is not, and is not intended to become, full repository coverage.

See `feature-index.md` for the current feature list.
